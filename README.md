# Seguir tus hábitos

## Descripción
Esta aplicación te ayuda a seguir tus hábitos. Puedes registrar lo que quieres mejorar cada día y consultar tus estadísticas para ver cómo vas avanzando.

## Funciones principales
- Seguir tus hábitos
- Ver tus estadísticas de progreso

## Cómo usar la aplicación
1. Abre la aplicación.
2. Agrega los hábitos que quieres seguir.
3. Marca cada día si cumpliste el hábito.
4. Revisa tus estadísticas para ver tu avance.

## Requisitos
- Completa esta parte según lo que usaste (por ejemplo: navegador web, Python, celular, etc.).
